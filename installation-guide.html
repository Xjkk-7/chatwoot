Chatwoot Customization Installation Guide

How to apply AI Assistant rebranding and enhanced analytics to your Chatwoot installation

Method 1: Using the JavaScript File

This is the simplest method and works with any Chatwoot installation:

  1. Download the deploy-customizations.js file
  2. Copy it to your Chatwoot server's public directory
  3. Add the following script tag to your Chatwoot's index.html file just before the closing </body> tag: 
    <script src="/deploy-customizations.js"></script>

Method 2: Browser Extension (Tampermonkey)

If you don't have access to modify the server files, you can use a browser extension:

  1. Install the Tampermonkey browser extension
  2. Create a new script and paste the entire contents of deploy-customizations.js
  3. Set it to run on your Chatwoot domain

Method 3: Full Docker Deployment

For a complete Chatwoot deployment with customizations:

  1. Clone our repository: 
    git clone https://github.com/yourusername/chatwoot-customizations.git
cd chatwoot-customizations
  2. Start the Docker containers: 
    docker-compose -f docker-compose.deploy.yml up -d
  3. Run the injection script: 
    # Linux/Mac
./inject-customizations.sh

# Windows
.\inject-customizations.ps1

Customizing the JavaScript

You can modify the JavaScript file to change the customization behavior:

  • Change the colors by modifying the CSS color values (e.g., #3B82F6 for AI Assistant)
  • Change the labels by modifying the content: "AI Assistant" values
  • Adjust the analytics panel metrics by modifying the HTML in the analyticsPanel.innerHTML section

The CSS selectors are designed to target Chatwoot's current DOM structure. If you're using a different version of Chatwoot, you may need to adjust these selectors.
