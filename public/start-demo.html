Getting Started

To run the full Support Hub application:

  1. Ensure Docker is installed on your system
  2. Run docker-compose up -d from the project root
  3. Access Support Hub at http://localhost:3000

For a quick demonstration of the features without installing Docker, you can view the demo page.
