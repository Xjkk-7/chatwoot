Support Hub Customizer

This page provides tools to customize your Chatwoot instance with Support Hub branding and enhanced features.

Bookmarklet Installation

Simple Method: Drag the following button to your bookmarks bar:

Support Hub

Click this bookmark when you're on your Chatwoot dashboard to activate Support Hub customizations.

Manual Installation

For permanent installation: Add these scripts to your Chatwoot instance:

  1. Copy the following files to your Chatwoot's public directory:
    • support-hub-inject.js
    • support-hub-style.css
    • support-hub-loader.js
    • support-hub-app-injector.js
  2. Add the following script tag to your Chatwoot's app/views/layouts/vueapp.html.erb file:
    <script src="/support-hub-app-injector.js"></script>

One-line Script

For quick testing, paste this in your browser console when on your Chatwoot dashboard:

fetch('https://raw.githubusercontent.com/Xjkk-7/chatwoot/support-hub-customization/public/support-hub-inject.js') .then(r => r.text()) .then(code => { const script = document.createElement('script'); script.textContent = code; document.body.appendChild(script); fetch('https://raw.githubusercontent.com/Xjkk-7/chatwoot/support-hub-customization/public/support-hub-style.css') .then(r => r.text()) .then(css => { const style = document.createElement('style'); style.textContent = css; document.head.appendChild(style); }); });
